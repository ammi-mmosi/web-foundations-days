About QuickNotes

QuickNotes is a lightweight notes app for jotting down ideas, reminders and to-dos without any setup. It keeps everything on one page so you can write, find and organise your notes quickly.

How to use QuickNotes

  1. Type your note into the text box on the Home page.
  2. Click "Add note" to save it to your list.
  3. Use the search box to find an older note.
  4. Click "Delete" next to a note to remove it.

Features

  • Instant note creation
  • Simple search
  • Works in any modern browser
  • Keyboard shortcuts for common actions

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search your notes
Delete Remove the selected note
